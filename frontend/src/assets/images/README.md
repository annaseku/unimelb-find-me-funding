# Campus background

`campus-background.jpg` is the original 3697 × 2771 pixel photograph of the Sidney Myer Asia Centre overlooking Swanston Street. It is kept at its native resolution without upscaling or recompression for sharp desktop backgrounds.

- Gallery: https://www.unimelb.edu.au/filming-on-campus/gallery/building-exteriors-2000-present
- Original: https://www.unimelb.edu.au/__data/assets/image/0011/2658674/SMAC-Aerial.jpg

The navy overlay is applied in `App.css` and shared by the home and results pages, leaving the photograph itself in colour.
