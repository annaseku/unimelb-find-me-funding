# University of Melbourne campus background images

These images are used as rotating page backgrounds for the Find Me Funding website.

They are sourced from the University of Melbourne campus photography collection:
https://www.unimelb.edu.au/filming-on-campus/gallery

## Usage notes

- These files are used as alternating background images in the homepage and results page.
- The app randomly chooses one image on each page load.
- The navy overlay and gradient are applied in `frontend/src/App.css` and `frontend/src/App.tsx`.
- Use these images only for the project website and in line with the University of Melbourne gallery usage terms.
