## 1. Sprint Goal

> **Goal:**  
> Define the foundations of the system through requirements analysis, user and motivational modelling, and the development of architectural models to establish the product's functional and technical direction.

### Success Criteria

| Goal | Metric / Success Criteria | Outcome |
| --- | --- | --- |
| Establish the core requirements of the product | Key functional and non-functional requirements identified | 🟢 |
| Understand intended users | User needs identified | 🟢 |
| Define user interactions  | User stories created and documented | 🟢 |
| Understand stakeholder motivations | Develop motivational model | 🟢 |
| Define system architecture | Initial architecture diagrams developed to represent system components and interactions | 🟢 |

---

## 2. Planned Work

At the beginning of the sprint, we planned to complete:

* Analyse project information
* Identify assumptions and open questions to confirm understanding of the product with the client
* Identify and prioritise requirements 
* Create user stories and motivational models to describe key system interactions 
* Design system architecture diagrams to inform future technical development

## 4. Issues / Blockers

| Issue | Impact | Resolution / Next Step |
| --- | --- | --- |

## 5. Sprint Outcome

**Sprint goal:** 🟢 Achieved 

**Summary:**

The team established an initial set of product requirements and developed user stories and motivational models to clarify the intended users, system goals, and stakeholder motivations. These artefacts provide a foundation for the UI/UX design and technical development planned for subsequent sprints.
