# Web Crawler — Project Home

## Project overview

A web-based tool for finding available research funding opportunities based on user inputs and returning funding opportunities ranked by attractiveness.

## Status

**In progress** — requirements and client clarification have been established; the team is moving into architecture and implementation planning.

## Current focus

* Finalise architecture decisions following client discussions
* Separate confirmed client requirements from engineering decisions
* Define crawler, indexing, data and LLM responsibilities
* Prepare implementation and testing plans

## Decision layer

Use the status labels below throughout the project:

* 🟢 **Confirmed** — agreed by the client or team
* 🟡 **Open** — requires clarification, investigation or discussion
* 🔵 **In progress** — currently being worked on
* ⚪ **Proposed** — suggested but not yet agreed
* 🔴 **Rejected** — considered and ruled out
